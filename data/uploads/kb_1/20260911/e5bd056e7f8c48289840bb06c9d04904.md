## 四、Python函数名
- 函数名要体现具体实现功能
- 注释清晰
- 入参出参格式、结构可在备注中添加

**函数示例**
```python
# 获取文件名
def get_file_name(file_dir, file_name):
    """检查文件及修改文件名"""
    # 获取当前工作目录
    current_directory = os.getcwd() if not file_dir else file_dir
    # 列出当前目录下的所有文件和目录
    files = [file for file in os.listdir(current_directory) if '凭证' in file and not '~$' in file]

    # 防止出现文件名修改后需要重复执行脚本情况
    if [file for file in os.listdir(current_directory) if file_name == file]:
        return f'{current_directory}/{file_name}'

    # 校验是否存在文件
    if not files:
        print(f"错误：文件夹内无凭证文件")
        sys.exit(1)

    # 校验文件数量
    if len(files) > 1:
        print(f"错误：凭证文件数量超过要求")
        print(f"文件夹内现有凭证文件名：{','.join(files)}")
        sys.exit(1)

    # 校验文件格式
    if files[0].split('.')[1] != 'xlsx':
        print(f"错误：凭证文件格式异常，请检查")
        print(f"文件夹内现有凭证文件名：{','.join(files)}")
        sys.exit(1)

    # 修改文件名
    try:
        os.rename(f'{current_directory}/{files[0]}', f'{current_directory}/{file_name}')
    except Exception as e:
        print(f"错误：文件修改失败，错误原因是：{str(e)}")
        sys.exit(1)
```

## 六、流程内容

1. **主流程职责**：用于调用其他子流程，可带有少量循环、判断指令，使用`Try‑Catch‑Finally`结构做异常捕获与资源释放。

```
Try 尝试执行
    调用流程：a配置（无返回结果）
    调用流程：b01金蝶web（无返回结果）
    调用流程：b02金蝶pc（无返回结果）
Catch 捕获异常，错误信息存入exception
    打印日志：exception
End Try
Finally 无论成败一定执行
    调用流程：z终止流程（无返回结果）
```

2. **子流程职责**：子流程指令按功能模块划分，单一子流程尽量只完成一类业务逻辑。

> 
> d1 核检‑是否新增部门.flow 流程步骤

1. **激活 Sheet 页**：根据 Sheet 页名称，激活 Excel 对象`工资汇总表excel_instance`中的工作表`核检1‑是否新增部门`
2. **刷新数据透视表**：在 Excel 对象`工资汇总表excel_instance`中刷新数据透视表
3. 【合计】分组
   - **批量向下填充 (公式)**：`工资汇总表excel_instance` H 列，行 4 ~ -1，填充公式：`=C4+D4+E4+F4+G4`
4. 【费用部门核检】分组
   - **批量向下填充 (公式)**：`工资汇总表excel_instance` K 列，行 4 ~ -3，填充公式：`=IF(COUNTIF([[999999核检公式.xlsx]Sheet1!$BQ:$BQ,B4)>0,...`
5. 【计提费用（工资社保公积金）验证】分组
   - **批量向下填充 (公式)**：`工资汇总表excel_instance` L 列，行 4 ~ -3，填充公式：`=SUMIFS([999999核检公式.xlsx]Sheet1!$D:$D,[999999核检公...`
6. 【差异】分组
   - **批量向下填充 (公式)**：`工资汇总表excel_instance` M 列，行 4 ~ -3，填充公式：`=H4‑L4`
7. 【开始核检数据】分组
   - **读取 Excel 内容**：读取`工资汇总表excel_instance`，范围：第 4 行 A 列 → -3 行 N 列，输出变量：`核检1excel_data`
   - **ForEach 列表循环**：遍历列表`核检1excel_data`，循环项存入`当前行`
8. **指令备注**：核心循环、判断逻辑，需要添加指令备注说明业务含义。

## 十一、其他

### 1. 重试机制

- 使用 For 次数循环嵌套 Try‑Catch 实现重试
- 需要重试的功能，执行重试前注意恢复页面初始状态

### 2. 程序开始前 / 后

- 程序结束务必执行关闭 Excel、关闭网页指令，释放进程占用

### 3. 打开网页

- 网页打开后执行窗口最大化指令

### 4. 配置文件

- 配置文件命名`配置.xlsx`，划分多个 sheet 存放配置项
- 配置文件只读取一次，解析结果存放在全局变量（list/dict）
- 全局变量调用方式：`glv['全局变量名']`
